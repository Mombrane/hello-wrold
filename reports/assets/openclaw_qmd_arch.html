OpenClaw QMD 三段式级联检索管道

BM25 粗筛 → Embedding 语义召回 → LLM Reranker 精排 | 基于 3 个本地 GGUF 模型

检索管道特征

  • • 三段级联：粗筛 → 召回 → 精排
  • • BM25 快速过滤大量无关文档
  • • Embedding 捕获语义相似性
  • • LLM Reranker 最终精排保精度

模型依赖

  • • 需要 Node.js ≥22 运行时
  • • 首次自动下载 ~2GB GGUF 模型
  • • 冷启动需加载 3 个模型 (~19s)
  • • 模型下载后可完全离线运行

能力边界

  • • ✅ 真正的语义理解（同义词泛化）
  • • ✅ 跨语言 Embedding 匹配
  • • ❌ 不支持组合推理（AND 查询）
  • • ❌ 无信任评分 / 矛盾检测
