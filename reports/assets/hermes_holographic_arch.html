Hermes Holographic 混合检索架构

FTS5 关键词 + Jaccard 词重叠 + HRR 相位代数 + Trust 评分 | 零模型依赖 · 纯 Python + SQLite

Holographic 核心优势

  • • 零模型依赖：不需要下载 2GB 模型
  • • 即时启动：无冷启动延迟
  • • 确定性编码：SHA-256 跨机器一致
  • • ~100ms 检索延迟（vs QMD 5-22s）

组合推理能力

  • • bind/unbind/bundle 代数操作
  • • 多实体 AND 查询原生支持
  • • 自动矛盾检测（记忆卫生）
  • • 实体关联发现（结构化上下文）

局限性

  • • ⚠️ 词袋级语义（不理解同义词）
  • • ❌ 不支持跨语言泛化
  • • ❌ 无 LLM Reranker / 查询扩展
  • • HRR 是近似语义，非真正理解
