📊 核心实验发现

  • Round-level 粒度综合最优，Fact-level 有信息损失
  • 键扩展的 merge 策略 > separate 策略
  • 弱 LLM 做时间推断会产生误报，必须用强 LLM（GPT-4o）
  • CoN 在 Oracle（完美检索）下仍有效，阅读策略独立于检索质量
  • 15-19% 实例检索正确但生成错误 → 阅读策略是优化空间
