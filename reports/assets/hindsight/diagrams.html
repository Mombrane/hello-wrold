16.1K GitHub Stars LongMemEval SOTA MIT License PostgreSQL + pgvector 2-Line Integration
R
Retain

将原始对话/文本输入系统。LLM 自动提取事实、实体、时间信息，构建时序实体记忆图（TEMPR）。支持分块策略和实体消歧。

R
Recall

四路并行检索：语义向量 + BM25 关键词 + 图扩散激活 + 时间范围过滤。RRF 融合排序后经 Cross-Encoder 精排，按 token 预算裁剪。

R
Reflect

Agentic 循环深度推理。层次化检索（Mental Models -> Observations -> Raw Facts），通过 tool calling 逐层深入，生成洞察与行动指令。

Application Layer -- AI Agent / Chatbot / Autonomous Agent
集成方式：LLM Wrapper (2行代码) / REST API / SDK (Python/Node.js) / MCP Server / 20+ 框架集成
Memory Operations Layer -- Retain / Recall / Reflect
三大核心操作：Retain 构建记忆图谱，Recall 多策略检索，Reflect 深度推理生成 Mental Models
Memory Organization Layer -- Four-Network Biomimetic Architecture
World Facts（世界知识）+ Experiences（经验）+ Mental Models（心智模型）+ Opinion Network（观点网络）
Storage Layer -- PostgreSQL + pgvector + pgvchord
Entity tables + Memory units + HNSW vector indexes + BM25 full-text + Graph links + Temporal indexes + Alembic migrations

Hindsight 记忆模型与存储结构

仿生四网络记忆组织 -- 世界知识 + 经验 + 心智模型 + 观点网络

W
World Facts（世界知识）

关于世界的客观事实，如"炉子会发热"。以结构化实体+关系存储，支持时间版本追踪。

entity_resolution temporal_versioning causal_links
E
Experiences（经验）

Agent 自身经历，如"我碰了炉子真的很痛"。第一人称视角，带情感和因果关系标注。

first_person emotion_tagged causal_relations
M
Mental Models（心智模型）

通过 Reflect 操作从原始记忆和经验中形成的高层理解。包含摘要、结构化内容、proof_count、历史版本。

reflect_generated structured_content version_history
O
Opinion Network（观点网络）

Agent 形成的观点和偏好。基于 Disposition 参数（formality/verbosity/warmth）调节推理风格。支持观点强化与衰减。

disposition_driven reinforcement background_merging

Hindsight 检索与注入机制

四路并行检索 + RRF 融合 + Cross-Encoder 精排 + Token Budget 裁剪

Recall 操作流程

S
Semantic Retrieval

pgvector HNSW 向量相似度搜索。Dense embedding 匹配语义相近的记忆。

K
Keyword Retrieval (BM25)

PostgreSQL 全文检索 + BM25 排序。精确匹配关键词，处理专有名词和缩写。

G
Graph Retrieval (Spreading Activation)

从匹配实体出发，沿图链接扩散激活。衰减机制控制扩散深度，发现间接关联。

T
Temporal Graph Retrieval

时间范围过滤 + 时间邻近度排序。处理"上周""上个月"等时间查询。

四路并行检索
Semantic + BM25 + Graph + Temporal
同时执行，独立返回结果集
→
RRF 融合
Reciprocal Rank Fusion
多路结果统一排序
→
Cross-Encoder
Jina Reranker 精排
query-document 交叉编码
→
Token Budget
按 token 预算裁剪
优先保留高分记忆
→
注入 LLM
System Prompt
上下文注入
A
Agent-Optimized Retrieval

Recall 输出经过特殊设计：不返回原始文档，而是返回结构化记忆片段，包含实体、时间、关系等元数据，让 LLM 能高效利用记忆上下文。

H
层次化 Reflect 检索

Reflect 时按层次检索：Mental Models（最高质量）-> Observations（整合知识）-> Raw Facts（原始真相）。通过 tool calling 逐层深入，最多 10 轮迭代。

Hindsight 核心优势

- 仿生记忆架构，最接近人类认知
- 4路并行检索 + Cross-Encoder 精排
- 自动 Observation 合并学习
- LongMemEval 独立验证 SOTA

适用场景

- 需要长期学习的 AI 员工
- 个性化对话 Agent

潜在考量

- 依赖 LLM 调用（成本较高）
- 需要 PostgreSQL 部署
- 学习曲线较陡
- 企业功能需 Cloud 版本
