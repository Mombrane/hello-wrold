MobileRun (DroidRun) 架构概览

多 Agent 协作 · LLM 驱动移动设备自动化 · v0.6.8

Reasoning Mode

  • • ManagerAgent 制定多步计划
  • • ExecutorAgent 逐步执行
  • • 反馈闭环：结果回传 Manager 决策
  • • 适合复杂任务（订机票、配置系统）

Direct Mode

  • • FastAgent XML 工具调用
  • • ReAct: Thought → Tool Call → Observe
  • • 无规划开销，响应快
  • • 适合简单任务（截图、发消息）

核心数据流

  • • a11y tree (~2KB) 为主要 UI 感知
  • • 截图仅在 vision=True 时附加
  • • Portal App 提供实时 UI 树 + 截图
  • • 状态共享：所有 Agent 读写同一 State
